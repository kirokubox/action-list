# action-list（仮名）

仕事以外のこれから24時間について「次やる順番」だけを並べ替える自分専用Webアプリです。

完了記録・回数・日付・締切は持ちません。「完了」「済み」という語もUIに使いません。

- かぞえ帳 = 回数・最終日
- Googleカレンダー = 実績時間
- 本アプリ = 次やる順番

というSOT（正本）分担を前提に、区切り（「あとで」）より上を「これから」、下を「今じゃない」として並べ替えるだけのシンプルな構成にしています。

## 開発コマンド

```powershell
npm install
npm run dev
```

スマホ実機で確認する場合（PCとスマホを同一Wi-Fiに）:

```powershell
npm.cmd run dev -- --host 0.0.0.0
```

本番ビルド確認：

```powershell
npm run build
```

## データの保存場所

- localStorage（キー：`action-list-data`）にのみ保存します。サーバー・ログイン・自動同期はありません
- バックアップはヘッダー右のメニュー「JSONを書き出す」から取得し、資料フォルダ（`05_開発・Webアプリ\13_action-list\backup_json`）などに保管してください
- 「JSONを取り込む」は追加型インポートです（既存idと重複する項目は追加しません）

## 正式名称・アイコンについて

アプリ名・配色・アイコンはすべて仮のプレースホルダーです。正式なデザインは後日差し替えます。
